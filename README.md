# 水下考古 · 潜次减压停留与标记放行台

直接打开 `index.html` 使用（数据保存在浏览器 localStorage，无需服务端）。

## 三个业务文件

| 文件 | 分层 | 职责 |
| --- | --- | --- |
| `rules.js` | 规则层（纯函数） | 免减压限值表、超限/安全停留判定、标记放行状态、复核换人校验、修订留档判定、提交指纹 |
| `records.js` | 记录层（localStorage） | 潜次/标记/复核/留档的增改查、幂等登记、修订归档、时间线、统计、导出 |
| `page.js` | 页面层（DOM） | 登记表单、潜次表、复核弹窗、平面图标记、筛选、统计条、导出 |
| `index.html` | 外壳 | 结构与样式，按 rules → records → page 顺序加载 |

## 业务规则

- **潜次登记**：登记编号、两名潜水员（不能同人）、最大深度、底部时间、安全停留勾选、登记提交人。
- **免减压限值**（空气潜水教学样表，就近就深取档，>40m 须减压）：
  12m/120、14m/95、16m/72、18m/56、20m/45、22m/35、25m/25、30m/20、35m/10、40m/9（分钟）。
  最大深度达到 30m 必须做安全停留（5m/3min）。
- **标记只进待复核**：潜次超过免减压限值，或达到 30m 却缺少安全停留时，其下所有标记为待复核
  （地图上虚线黄边），**不计入时间线、统计的放行口径和导出**；合规潜次的标记自动放行。
- **复核放行**：复核人必须与登记提交人不同（换人），必须填写停留深度（须小于最大深度）与时长，
  通过后该潜次标记放行并进入时间线/导出，时间线展示复核人与停留参数。
- **修订与留档**：修订最大深度或底部时间 → 旧版本（潜次+标记+复核快照）整体留档（页面可折叠查看），
  版本号 +1，旧放行与旧导出失效，标记按新参数重新判定；改潜水员等其他字段不留档、不升版。
- **重复/并发提交**：按内容指纹在 10 秒窗口去重，重复点击或并发提交沿用首次结果
  （并发调用共享同一落盘 Promise，等待方标记为去重命中），不会产生重复潜次/标记。
- **口径一致**：筛选同时作用于地图、列表、时间线、统计条和导出；状态由规则实时推导，
  刷新页面后标记状态、统计、留档与筛选/视图偏好保持一致。
- **导出**：仅导出当前筛选下已放行的潜次与标记（含复核停留信息），文件名随筛选类型变化；
  待复核数据与旧版本留档不导出。
