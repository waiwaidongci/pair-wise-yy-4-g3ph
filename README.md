# 潜次减压停留与标记放行台

在水下考古潜水记录基础上扩展的减压停留与标记放行台。直接打开 `index.html` 使用。

## 文件划分（三个业务文件）

| 文件 | 业务职责 |
| --- | --- |
| `js/dive-rules.js` | 规则：免减压限值表、安全停留判定、潜次/复核校验、修订失效字段判定（纯函数） |
| `js/dive-records.js` | 记录：潜次与标记状态机、换人复核、修订留档、幂等提交、localStorage 持久化与变更广播 |
| `js/app.js` | 页面：地图打点、四个视图（标记列表/潜次时间线/待复核放行台/潜次登记）、筛选、统计、导出 |
| `index.html` | 页面外壳与样式，按 规则 → 记录 → 页面 顺序引入 |

## 业务规则

- **潜次登记**：登记编号（`字母-序号`，如 `DIVE-03`，不可重复）、两名潜水员（不可同人）、最大深度、底部时间，另填安全停留时长。
- **免减压限值**：按内置 NDL 表取不小于实际深度的最浅一档（12m/120min … 40m/9min）。深度 > 12m 须有 ≥3min 安全停留。
- **标记提交**：
  - 潜次合规（未超 NDL 且有安全停留）→ 标记直接**已放行**；
  - 超免减压限值或缺安全停留 → 标记**只进待复核**，不计入潜次时间线、不进入导出 JSON。
- **复核放行**：复核人必须换人（不能是该潜次两名潜水员之一），并填写停留深度（>0 且浅于最大深度）与停留时长（1–60 分钟）；通过后标记才放行。
- **修订失效**：修订潜次的**最大深度或底部时间**会使该潜次全部已放行标记失效、退回待复核并重新换人复核；潜次旧版本与每次放行失效均留档（潜次视图底部可查）。仅改安全停留等不触发失效。
- **重复/并发提交**：提交、复核、修订、登记均带幂等键；同一提交的重复点击或并发调用复用首次结果（只落一条、只放行一次）。
- **一致刷新**：筛选（潜次/类型/状态）、统计、地图、列表共用同一份过滤快照；筛选条件持久化，刷新页面与多标签页存储事件后状态保持一致。

## 导出

点击右上角「导出已放行 JSON」，只包含已放行标记与各潜次的合规评估；待复核标记不进明细，仅给出 `excludedPendingCount` 计数。
